# 16. 관리자 페이지 (BE-1)

> 담당 BE: 이하연 · 대상 FE: 홍근
> FE 파일: `features/admin/...`, `/admin/accounts`, `/admin/rooms`, `/admin/reports`, `/admin/notices`, `/admin/audit-logs` (+ 통계 대시보드)
> 공통 규칙은 `00-공통규칙.md` 참고.

## 권한
- 모든 API 는 `/api/v1/admin/**` 이고 **`role=ADMIN` 계정의 Bearer 토큰**만 통과한다.
- 일반 사용자 → `403 COMMON_FORBIDDEN`. 관리자 메뉴 노출 여부는 `GET /api/v1/accounts/me` 의 `role` 로 판단(02 문서).
- 관리자가 상태를 바꾸는 API(정지, 역할 변경, 방 비활성, 신고 처리, 공지 CUD)는 **감사 로그**에 자동 기록된다.
- 목록은 모두 Page (`page` 0부터, `size` 기본 20, 최대 100).
- 날짜 필터(`joinedFrom`, `from`, `to` …)는 **한국 날짜 `yyyy-MM-dd`**, 양 끝 포함.

## 회원 (`/admin/accounts`)

### 1. 회원 목록

```
GET /api/v1/admin/accounts?keyword=하연&provider=KAKAO&status=ACTIVE&role=USER&joinedFrom=2026-11-01&joinedTo=2026-11-30&page=0&size=20
```

| 파라미터 | 값 |
|---|---|
| `keyword` | 이름·이메일 부분 검색 |
| `provider` | `GOOGLE` \| `KAKAO` \| `NAVER` |
| `status` | `ACTIVE` \| `SUSPENDED` \| `WITHDRAWN` |
| `role` | `USER` \| `ADMIN` |
| `joinedFrom`, `joinedTo` | 가입일 `yyyy-MM-dd` |

`content[]`: AdminAccountResponse
```json
{
  "accountId": 12,
  "name": "이하연",
  "email": "user@kakao.com",
  "provider": "KAKAO",
  "role": "USER",
  "status": "SUSPENDED",
  "suspendedUntil": "2026-11-29T10:00:00+09:00",
  "createdAt": "2026-11-01T10:00:00+09:00",
  "lastLoginAt": "2026-11-22T09:00:00+09:00"
}
```
- `suspendedUntil`: 정지 중이 아니거나 **영구 정지**면 `null` → `status` 와 함께 보고 "영구" 표시.

### 2. 회원 상세 — AdminAccountDetailResponse

1번 필드 **전부 + 아래 필드**가 같은 높이(평평하게)로 온다.
```json
{
  "accountId": 12, "name": "...", "...": "(1번 필드들)",
  "roomCount": 3,
  "ownedRoomCount": 1,
  "reportBlockedUntil": null,
  "suspensions": [
    {
      "suspensionId": 5,
      "period": "DAYS_7",
      "reason": "욕설 반복",
      "startedAt": "2026-11-22T10:00:00+09:00",
      "endsAt": "2026-11-29T10:00:00+09:00",
      "releasedAt": null,
      "admin": { "accountId": 1, "name": "관리자" }
    }
  ]
}
```
- `reportBlockedUntil`: 허위 신고 누적으로 신고 기능이 막힌 기한. 없으면 `null`.
- `suspensions`: 정지 이력. `endsAt: null` = 영구, `releasedAt` 이 있으면 관리자가 조기 해제한 것.

| 에러 | HTTP |
|---|---|
| `ACCOUNT_NOT_FOUND` | 404 |

### 3. 정지

```
POST /api/v1/admin/accounts/{accountId}/suspension
{ "period": "DAYS_7", "reason": "욕설 반복", "reportId": 31 }
```
| 필드 | 규칙 |
|---|---|
| `period` | 필수. `DAYS_3` \| `DAYS_7` \| `DAYS_30` \| `PERMANENT` |
| `reason` | 필수, 최대 500자. 대상에게 알림으로 전달됨 |
| `reportId` | 선택. 신고 처리에서 이어진 정지면 신고 ID |

- 응답: 갱신된 회원 상세(2번).
- 대상은 **즉시 로그아웃**(refresh 토큰 삭제)되고 다음 요청부터 `403 AUTH_ACCOUNT_SUSPENDED`. 알림 `ACCOUNT_SUSPENDED`.
- 정지 기간이 끝나면 스케줄러가 자동 해제한다.

| 에러 | HTTP | 뜻 |
|---|---|---|
| `ADMIN_CANNOT_SUSPEND_ADMIN` | 409 | 관리자는 정지 불가 |
| `ADMIN_ACCOUNT_WITHDRAWN` | 409 | 탈퇴한 계정 |
| `ADMIN_ALREADY_SUSPENDED` | 409 | 이미 정지 중 |
| `ACCOUNT_NOT_FOUND` | 404 | |

### 4. 정지 해제

```
DELETE /api/v1/admin/accounts/{accountId}/suspension
```
- 응답: 회원 상세. 대상에게 알림.

| 에러 | HTTP | 뜻 |
|---|---|---|
| `ADMIN_NOT_SUSPENDED` | 409 | 정지 상태가 아님 |

### 5. 역할 변경

```
PUT /api/v1/admin/accounts/{accountId}/role
{ "role": "ADMIN" }
```
- 응답: 회원 상세. 바뀐 역할은 대상이 **토큰을 다시 받은 뒤**(재로그인 또는 refresh) 적용된다.

| 에러 | HTTP | 뜻 |
|---|---|---|
| `ADMIN_CANNOT_CHANGE_OWN_ROLE` | 409 | 내 역할은 못 바꿈 |
| `ADMIN_ACCOUNT_WITHDRAWN` | 409 | 탈퇴한 계정 |
| `ADMIN_LAST_ADMIN` | 409 | 마지막 관리자를 USER 로 내릴 수 없음 |

## 신고 (`/admin/reports`)

### 상태 흐름
```
RECEIVED(접수) ──12 review──▶ IN_PROGRESS(검토 중) ──13 resolve──▶ RESOLVED(처리 완료)
      └───────────────────────────────┴──────────14 reject──▶ REJECTED(반려)
```
- 12번을 건너뛰고 RECEIVED 에서 바로 13/14 도 가능.
- RESOLVED/REJECTED 에서 다시 처리하면 `409 ADMIN_REPORT_ALREADY_PROCESSED`.

### 10. 신고 목록

```
GET /api/v1/admin/reports?status=RECEIVED&targetType=MESSAGE&reason=ABUSE&page=0&size=20
```
| 파라미터 | 값 |
|---|---|
| `status` | `RECEIVED` \| `IN_PROGRESS` \| `RESOLVED` \| `REJECTED` |
| `targetType` | `CARD` \| `COMMENT` \| `MESSAGE` |
| `reason` | `ABUSE` \| `SPAM` \| `INAPPROPRIATE_FILE` \| `PRIVACY` \| `ETC` |

`content[]`: AdminReportResponse
```json
{
  "reportId": 31,
  "targetType": "MESSAGE",
  "reason": "ABUSE",
  "status": "RECEIVED",
  "reporter": { "accountId": 20, "name": "김모아" },
  "targetAccount": { "accountId": 12, "name": "이하연" },
  "room": { "roomId": 3, "name": "캡스톤 5조" },
  "createdAt": "2026-11-14T10:00:00+09:00",
  "overdue": true
}
```
- `overdue: true` = 접수 후 **7일이 지났는데 미처리**. 같은 페이지 안에서 맨 위로 올려 준다 → 빨간 배지 등으로 강조.

### 11. 신고 상세 — AdminReportDetailResponse
10번 필드 전부 + 아래 (평평하게)
```json
{
  "...": "(10번 필드들)",
  "detail": "신고자가 쓴 상세 내용",
  "snapshot": "{\"content\":\"신고 당시 원문\"}",
  "targetDeleted": false,
  "action": null,
  "actionReason": null,
  "handledBy": null,
  "handledAt": null
}
```
- `snapshot`: 신고 **당시** 내용. **JSON 문자열**이므로 `JSON.parse(snapshot).content` 로 꺼낸다. 카드는 `제목\n내용`.
- `targetDeleted`: 원본이 지금 지워졌는지.
- 처리 후에는 `action`, `actionReason`, `handledBy {accountId,name}`, `handledAt` 이 채워진다.

| 에러 | HTTP |
|---|---|
| `REPORT_NOT_FOUND` | 404 |

### 12. 검토 시작

```
POST /api/v1/admin/reports/{reportId}/review
(본문 없음)
```
- `IN_PROGRESS` 로 바꾸고 상세(11번)를 돌려준다. 상세 화면을 열 때 "검토 시작" 버튼으로.

### 13. 처리(조치)

```
POST /api/v1/admin/reports/{reportId}/resolve
{ "action": "SUSPEND_ACCOUNT", "actionReason": "욕설 반복", "suspensionPeriod": "DAYS_7", "falseReport": false }
```
| 필드 | 규칙 |
|---|---|
| `action` | 필수. `DELETE_CONTENT`(신고된 글 삭제) \| `SUSPEND_ACCOUNT`(작성자 정지) \| `WARN`(경고) \| `NONE`(조치 없음) |
| `actionReason` | 필수, 최대 500자. 신고자·대상자에게 알림으로 전달됨 |
| `suspensionPeriod` | `action=SUSPEND_ACCOUNT` 일 때 **필수** (`DAYS_3`…`PERMANENT`) |
| `falseReport` | 선택. `true` 면 허위 신고로 표시 |

- 응답: 상세(11번). 신고자·대상자에게 알림 `REPORT_PROCESSED`.
- `SUSPEND_ACCOUNT` 는 3번 정지와 같은 효과(정지 이력에 `reportId` 연결).

| 에러 | HTTP | 뜻 |
|---|---|---|
| `COMMON_INVALID_INPUT` | 400 | `SUSPEND_ACCOUNT` 인데 `suspensionPeriod` 없음 등 |
| `ADMIN_REPORT_ALREADY_PROCESSED` | 409 | 이미 처리/반려됨 |
| `ADMIN_ALREADY_SUSPENDED` | 409 | 대상이 이미 정지 중 → 다른 action 으로 |
| `ADMIN_CANNOT_SUSPEND_ADMIN` | 409 | 대상이 관리자 |

### 14. 반려

```
POST /api/v1/admin/reports/{reportId}/reject
{ "actionReason": "규정 위반이 아닙니다", "falseReport": true }
```
- `actionReason` 필수(최대 500자). 신고자에게 알림.

### 허위 신고 제재 (13·14 공통)
`falseReport: true` 로 처리된 신고가 **30일 안에 3건** 쌓이면, 그 신고자는 **30일간 신고 불가**(`REPORT_BLOCKED`). 회원 상세의 `reportBlockedUntil` 에 표시된다.

## 통계 (대시보드)

### 20. 서비스 통계

```
GET /api/v1/admin/stats/overview?unit=DAY&from=2026-11-01&to=2026-11-22
```
| 파라미터 | 값 |
|---|---|
| `unit` | 필수. `DAY` \| `WEEK` \| `MONTH` (구간 길이) |
| `from`, `to` | 필수. `yyyy-MM-dd` (KST), 양 끝 포함 |

```json
{
  "totals": { "accounts": 120, "rooms": 35, "messages": 8812 },
  "series": [
    { "periodStart": "2026-11-01", "newAccounts": 5, "activeAccounts": 40, "newRooms": 2, "messages": 310 }
  ],
  "aggregatedAt": "2026-11-22T14:30:00+09:00"
}
```
- `totals`: 지금 기준 전체 누적.
- `series`: `from` 부터 `unit` 간격으로 끊은 구간별 값. `periodStart` 는 구간 첫날(`yyyy-MM-dd`). `activeAccounts` = 그 구간에 한 번이라도 접속한 계정 수.
- 기간이 길고 `unit=DAY` 면 응답이 커지니 그래프 폭에 맞게 unit 을 고르세요.

### 21. AI 사용량 통계

```
GET /api/v1/admin/stats/ai-usage?unit=WEEK&from=2026-11-01&to=2026-11-22&feature=SUMMARY
```
- `feature`(선택): `ASSISTANT` \| `SUMMARY` \| `CONFLICT` \| `COMPROMISE` \| `TONE` \| `LAYOUT` \| `TASK_RECOMMEND`

```json
{
  "byFeature": [
    { "feature": "SUMMARY", "calls": 120, "failedCalls": 3, "promptTokens": 50000, "outputTokens": 12000, "costAmount": 1.25 }
  ],
  "series": [
    { "periodStart": "2026-11-01", "feature": "SUMMARY", "calls": 40, "costAmount": 0.41 }
  ],
  "threshold": { "costAmount": 80, "exceeded": false }
}
```
- `threshold.exceeded: true` → 기간 비용 합계가 기준(현재 80)을 넘음 → 경고 배너.

### 22. 감사 로그 (`/admin/audit-logs`)

```
GET /api/v1/admin/audit-logs?adminId=1&actionType=ACCOUNT_SUSPEND&targetType=ACCOUNT&from=2026-11-01&to=2026-11-22&page=0&size=20
```
| 파라미터 | 값 |
|---|---|
| `adminId` | 작업한 관리자 계정 ID |
| `actionType` | 아래 표 |
| `targetType` | `ACCOUNT` \| `ROOM` \| `REPORT` \| `NOTICE` |
| `from`, `to` | `yyyy-MM-dd` |

| actionType | 뜻 |
|---|---|
| `ACCOUNT_SUSPEND` / `ACCOUNT_RELEASE` | 정지 / 정지 해제 |
| `ROLE_CHANGE` | 역할 변경 |
| `ROOM_INACTIVATE` / `ROOM_REACTIVATE` | 방 비활성 / 재활성 |
| `REPORT_REVIEW` / `REPORT_RESOLVE` / `REPORT_REJECT` | 신고 검토 / 처리 / 반려 |
| `NOTICE_CREATE` / `NOTICE_UPDATE` / `NOTICE_DELETE` | 공지 등록 / 수정 / 삭제 |

`content[]`: AuditLogResponse
```json
{
  "auditLogId": 101,
  "admin": { "accountId": 1, "name": "관리자" },
  "actionType": "ACCOUNT_SUSPEND",
  "targetType": "ACCOUNT",
  "targetId": 12,
  "detail": "{\"period\":\"DAYS_7\",\"reason\":\"욕설 반복\"}",
  "ipAddress": "203.0.113.10",
  "createdAt": "2026-11-22T10:00:00+09:00"
}
```
- `detail` 은 **JSON 문자열**(없으면 `null`). 필요하면 `JSON.parse`.
