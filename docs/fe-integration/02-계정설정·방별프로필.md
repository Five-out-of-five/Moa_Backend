## 공통 응답: MyAccountResponse

1·2·3번이 같은 모양을 돌려준다. 저장 후 다시 조회할 필요 없이 응답으로 화면을 갱신하면 된다.

```json
{
  "accountId": 12,
  "name": "이하연",
  "email": "user@kakao.com",
  "provider": "KAKAO",
  "role": "USER",
  "toneMode": "OFF",
  "lastRoomId": 3,
  "createdAt": "2026-11-01T10:00:00+09:00"
}
```

| 필드 | 설명 |
|---|---|
| `role` | `ADMIN` 이면 프로필 메뉴(`ProfileMenu.tsx`)에 관리자 페이지 진입 버튼 노출 |
| `toneMode` | `OFF`(끔) / `POLISH`(다듬기) / `POLITE`(공손하게) |
| `lastRoomId` | 로그인 직후 들어갈 방. 없으면 `null` → 방 목록으로 |

## 1. 내 계정 조회

```
GET /api/v1/accounts/me
```
로그인 직후, 새로고침 후 첫 진입 때 호출. 에러는 공통(401)만.

## 2. 이름 변경

```
PATCH /api/v1/accounts/me
{ "name": "새이름" }
```
- `name`: 필수, 2~20자, 한글·영문·숫자·공백만.
- 이 이름은 **계정 이름**이다. 방 안에서는 방 닉네임이 우선 표시되고, 닉네임이 없을 때만 계정 이름이 보인다.

| 에러 | HTTP | 처리 |
|---|---|---|
| `COMMON_INVALID_INPUT` | 400 | `errors[].field == "name"` |

## 3. AI 말투 설정

```
PATCH /api/v1/accounts/me/ai-settings
{ "toneMode": "POLITE" }
```
- `toneMode`: 필수, `OFF` | `POLISH` | `POLITE`. 다른 값은 400.

## 4. 마지막 방 저장

```
PUT /api/v1/accounts/me/last-room
{ "roomId": 3 }
```
- 응답 `data: null`.
- 방에 들어갈 때마다(방 전환 `WorkspaceSwitcher.tsx` 등) 호출. 다음 로그인 때 `lastRoomId` 로 돌아온다.
- 실패해도 화면 동작에 영향이 없으니 결과를 기다리지 않고(fire-and-forget) 불러도 된다.

## 5. 탈퇴 가능 여부

```
GET /api/v1/accounts/me/withdrawal-check
```
```json
{
  "withdrawable": false,
  "ownedRooms": [ { "roomId": 3, "name": "캡스톤 5조", "memberCount": 4 } ]
}
```
- 내가 **방장인 방이 하나라도 있으면** `withdrawable: false`. 탈퇴 다이얼로그(`AccountDialogs.tsx`)에서 `ownedRooms` 를 보여 주고 "방장을 넘기거나 방을 삭제해 주세요" 안내 → 03 문서의 방장 위임 / 방 삭제로 연결.

## 6. 회원 탈퇴

```
DELETE /api/v1/accounts/me
Content-Type: application/json
{ "confirmText": "탈퇴합니다" }
```
- DELETE 이지만 **본문이 있다**. `fetch(url, { method: "DELETE", headers: {...}, body: JSON.stringify(...) })`
- `confirmText` 는 정확히 **`탈퇴합니다`** (띄어쓰기 없음). 사용자가 입력한 값을 그대로 보낸다.
- 성공 시 `data: null`, refresh 쿠키 삭제. FE 는 토큰을 지우고 랜딩으로 이동.
- 탈퇴한 소셜 계정으로는 다시 가입할 수 없다(로그인 시 `AUTH_REJOIN_RESTRICTED`). 다이얼로그에 안내 문구를 넣어 주세요.
- 탈퇴하면 그동안 쓴 글·메시지의 작성자는 `memberStatus: WITHDRAWN`, 이름·사진 `null` 로 보인다.

| 에러 | HTTP | 처리 |
|---|---|---|
| `ACCOUNT_WITHDRAW_CONFIRM_MISMATCH` | 400 | 확인 문구 틀림 |
| `ACCOUNT_OWNED_ROOM_EXISTS` | 409 | 방장인 방이 남아 있음 → 5번 다시 호출해 목록 표시 |

## 7. 방별 내 프로필 설정

```
PATCH /api/v1/rooms/{roomId}/members/me/profile
{ "nickname": "하연", "profileFileId": 41, "positionLabel": "백엔드" }
```

**보낸 키만 바뀐다.** 바꿀 필드만 보내면 된다.

| 필드 | 키를 안 보냄 | 값을 보냄 | `null` 을 보냄 |
|---|---|---|---|
| `nickname` | 그대로 | 변경 | 지움 (계정 이름으로 표시) |
| `profileFileId` | 그대로 | 이미지 교체 | 지움 (기본 이미지) |
| `positionLabel` | 그대로 | 변경 | 지움 |

예: 닉네임만 바꾸기 `{ "nickname": "새닉" }` → 이미지·역할 표시는 그대로.

| 필드 | 규칙 |
|---|---|
| `nickname` | 2~20자, 한글·영문·숫자·공백만. 방 안에서 이름 대신 표시. 같은 방의 다른 활동 멤버와 중복 불가 |
| `profileFileId` | 방 프로필 이미지. `purpose=PROFILE_IMAGE` 로 **이 방에** 내가 올린 파일 ID |
| `positionLabel` | 최대 20자. 역할 표시(예: "디자인") |

응답 `data`: MemberProfileResponse
```json
{
  "accountId": 12,
  "memberStatus": "ACTIVE",
  "displayName": "하연",
  "profileImageUrl": "https://d3fhahas6mrxzx.cloudfront.net/public/...",
  "positionLabel": "백엔드",
  "role": "OWNER",
  "online": true,
  "latestMood": { "mood": "GOOD", "comment": "오늘도 화이팅" },
  "canStartDirectMessage": false
}
```
- 저장되면 같은 방 사람들에게 실시간 이벤트 `MEMBER_UPDATED` 가 간다(BE-3 STOMP 가이드 참고).

### 최초 프로필 설정 (`FirstProfileForm.tsx`)
- 방에 처음 들어가면 `GET /api/v1/rooms/{roomId}` 응답의 `needsProfileSetup: true` → 최초 프로필 폼을 띄운다.
- 이 API 를 한 번 호출하면(건너뛰기 = 빈 본문 `{}` 로 호출. 빈 문자열 `""` 은 길이 검증에 걸려 400) `needsProfileSetup` 이 `false` 가 된다.

### 이미지 올리는 순서
1. `POST /api/v1/rooms/{roomId}/files?purpose=PROFILE_IMAGE` (multipart `file`) → `fileId`, `previewUrl`
2. 미리보기는 `previewUrl` 로 바로 표시
3. 저장 버튼 → 이 API 에 `profileFileId: fileId`
4. 업로드 후 저장을 취소하면 `DELETE /api/v1/rooms/{roomId}/files/{fileId}` 로 지워 주세요.

| 에러 | HTTP | 처리 |
|---|---|---|
| `COMMON_INVALID_INPUT` | 400 | 형식 위반 → `errors[].field` |
| `MEMBER_NICKNAME_DUPLICATED` | 409 | "이미 이 방에서 쓰는 닉네임입니다" (닉네임 칸 옆) |
| `ROOM_NOT_MEMBER` | 403 | 이 방 멤버가 아님 |
| `ROOM_NOT_FOUND` | 404 | 없는 방 |
| `FILE_NOT_FOUND` | 404 | 다른 방 파일이거나 없는 파일 |
| `FILE_NOT_OWNER` | 403 | 남이 올린 파일 |
| `FILE_PURPOSE_MISMATCH` | 400 | `PROFILE_IMAGE` 로 올린 파일이 아님 |
